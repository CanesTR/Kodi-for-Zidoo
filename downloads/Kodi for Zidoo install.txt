IMPORTANT: CURRENT LIMITATIONS
- Use a local media path beginning with /storage/.
- SMB/NAS paths are not supported yet, including smb://127.0.0.1/ paths
  used to access an HDD attached to the Zidoo.
- Select media inside Kodi's Movies, TV shows or Music videos library.
  Playback from Videos > Files, home shortcuts and widgets is not reliably
  routed to Zidoo. The current test build adds diagnostics, not a shortcut fix.
- The Helper's test field needs a complete local movie filename, not a folder.
- This launches Zidoo's native player; it does not redirect playback to ZDMC.
- Kodi is not included. Users do not need Android Studio or to build an APK.

INSTALLATION
1. Copy the Helper APK and ONE add-on ZIP to a USB drive.
2. On Zidoo, open File Manager and install the Helper APK. Allow installation
   from that source if Android requests it. Existing testers should update
   the Helper without uninstalling it.
3. Open the Helper. For first-time setup, use a complete /storage/... movie
   path to run a local playback test, then save the diagnostic report.
   This also checks that Kodi can access the Helper's shared report.
4. In Kodi, go to Settings > System > Add-ons and enable Unknown sources.
5. Go to Add-ons > Install from zip file and select the add-on ZIP.
   Do not select a source ZIP or the outer release package.
   If testing 0.7.20, install that ZIP instead of 0.7.19.
6. Fully close and reopen Kodi.
7. Make sure the test video is scanned into Kodi's video library.
   Open Movies, TV shows or Music videos and select the item there.
   Press OK/Select or Play. Zidoo's native player should open.
8. Exit playback normally to return the final position to Kodi.

Native Zidoo resume is enabled by default. Watched marking is automatic:
95% final playback position in 0.7.19; 90% in 0.7.20.
Seeking counts toward that position. There is no watched switch.
Long-press should open Kodi's context menu. Eligible local library items also
offer Play with Zidoo. Arbitrary add-on streams are not supported by this test.

COMPATIBILITY AND KNOWN ISSUES
Tested on Z30 Pro, firmware 1.3.45, Android 11, Kodi 22 beta2 ARM 32-bit.
A tester reports successful local-library playback, resume and watched marking
on Z9X 8K, firmware 1.3.45, Kodi 22 beta2 ARM 32-bit, Arctic Horizon 2.
Other models, Kodi versions and Maven builds remain unverified.

Kodi can restart during native playback. Home may appear before the saved
library list is restored. Neither build fixes this:
https://github.com/xbmc/xbmc/issues/29691

If a pending/queue message appears, record its exact text and save a Helper
diagnostic report before clearing app data. Only discard a pending session
when no Zidoo video is playing. Do not repeatedly launch while it is pending.

REPORTING A TEST
Include model, firmware, Android version, exact Kodi version/build, skin,
add-on and Helper versions, and whether you used the library, Files or a widget.
Include one complete media path without credentials, the exact error message,
and playback/resume/watched/return results. Review logs before sharing; never
post passwords or credential XML files.

The 0.7.20 build passed 21 automated tests; device testing is pending.
0.7.19 removes the experimental Python handoff and only bridge-owned test rules.
